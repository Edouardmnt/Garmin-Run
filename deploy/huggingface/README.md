# Foulée : démo en ligne

Tableau de bord d'un projet personnel data & IA sur la course à pied : charge d'entraînement, récupération, temps prédits
(avec leur fiabilité mesurée), planning jusqu'à une course, et coach.

**Toutes les données de cette démo sont synthétiques** : aucune donnée réelle, aucun compte Garmin. Le coach répond ici
par des règles ; dans le projet, c'est un modèle de langage qui tourne en local (Ollama).

Code, architecture et résultats : https://github.com/Edouardmnt/Garmin-Run
